# Get_MP_language
this is the repository to get the MP language.
# how to use:
1. download the needed files.
2. open "Visual code studios"
3. click control + shift + x to open extensions.
4. click at the tree dots ("...")
5. choose "Install from VSIX"
6. choose the downloaded VSIX file.
# to get "getex" (pip install):
1. unzip the zipfile.
2. open the folder
3. fined getex.cmd and run it.
4. follow the readme file for instructions.
